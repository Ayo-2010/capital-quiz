# Capital Atlas Quiz

A text-only capital cities quiz with regions, timers and a full review at the end.

## Features

- Region picker for the World, Africa, Europe, Asia, the Americas and Oceania
- Round lengths of 5, 10 or 20 questions built from a shuffled pool
- Over one hundred and eighty country and capital pairs, with distractors from the same region
- Ask count, running score, streak and a fifteen second countdown that auto-advances
- Green and red answer marking that reveals the correct capital after a miss
- Results screen with the final score, the saved best score per region and a per question review
- Keyboard support with 1 to 4 to answer and Enter to move on
- Best scores stored per region in localStorage

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.
